# GainTrack

تطبيق آيفون (Swift/SwiftUI) لتتبع نظام زيادة الوزن والعضلات — Dark Mode فقط،
بواجهة عربية RTL كاملة، وتخزين محلي (SwiftData) مع مزامنة iCloud/CloudKit.

الهدف الافتراضي: **57 كجم ➔ 75 كجم** (الطول 176 سم) — قابل للتعديل من الإعدادات.

## البنية

```
FitnessTracker/
├── App/                  # نقطة الدخول، AppDelegate، الإعدادات العامة
├── Core/
│   ├── Models/            # SwiftData models (DailyLog, TaskCompletion, ProgressPhoto...)
│   ├── Services/          # الإشعارات، الكاميرا، تخزين الصور، PDF، تايم لابس، النسخ الاحتياطي
│   ├── Extensions/        # الثيم (لون أسود/أخضر نيون)
│   └── Utilities/         # منطق "يوم التتبع" (5 مساءً → 5 صباحًا)
├── Features/
│   ├── Today/              # التاب الأول: اليوم
│   ├── Stats/               # التاب الثاني: الإحصائيات
│   ├── Gallery/             # التاب الثالث: المعرض
│   ├── Settings/            # التاب الرابع: الإعدادات والجدول
│   ├── Camera/              # كاميرا توثيق المهام + كاميرا 5 صباحًا
│   └── Shared/              # RootTabView
├── Shortcuts/              # Siri App Intents (تسجيل مية / وزن بالصوت)
├── Widgets/                # Widget Extension (الشاشة الرئيسية + شاشة القفل)
└── Tests/
```

## المميزات المنفذة

- **جدول زمني يومي** يبدأ 5:00 م وينتهي 5:00 ص، بمنطق مركزي في `TrackingDay`.
- **إشعارات مجدولة**: دواء (5 م)، تجهيز الجيم (5:30 م أيام التمرين فقط)، مكملات (10 م)،
  مراجعة الصباح (5 ص)، ومياه كل ساعتين من 2 ظهرًا حتى تجميد كامل 6ص–2ظهرًا.
- **جدول تمرين أسبوعي ثابت** معروض في تاب الإعدادات.
- **تحقق بالصور**: كل مهمة (دواء/جيم/مكملات) تتطلب صورة لإتمامها.
- **كاميرا Quick Snap للساعة 5 صباحًا** مع إطار توجيه شفاف، ثم لوحة أرقام لتسجيل الوزن،
  ثم شاشة مراجعة اليوم.
- **محرك تتبع الوزن** مع progress bar وخط هدف ثابت في الرسم البياني (Swift Charts).
- **تخزين خاص للصور** داخل Documents الخاصة بالتطبيق (ليس مكتبة الصور)، مع زر تصدير يدوي،
  وألبومات ذكية (5AM / الدواء / المكملات / الكل).
- **مقارنة قبل/بعد** بشريط سحب تفاعلي، و**مولّد فيديو تايم لابس** (AVFoundation → MP4).
- **الستريك** ومراجعة اليوم عند اكتمال كل المهام.
- **تقرير PDF** أسبوعي/شهري (التزام + منحنى وزن + شبكة صور).
- **Siri Shortcuts** لتسجيل المياه والوزن بالصوت.
- **Widgets** للشاشة الرئيسية وشاشة القفل (تمرين اليوم، المياه، الستريك) عبر App Group مشترك.
- **مزامنة iCloud تلقائية** (CloudKit) + **نسخ احتياطي يدوي** (تصدير/استيراد zip).

## البناء

المشروع يستخدم [XcodeGen](https://github.com/yonaskolb/XcodeGen):

```bash
brew install xcodegen
cd FitnessTracker
xcodegen generate
open GainTrack.xcodeproj
```

قبل التشغيل على جهاز حقيقي:
1. فعّل **iCloud (CloudKit)** و**App Groups** (`group.com.gaintrack.app`) في Signing & Capabilities
   لكل من التطبيق الرئيسي والـ Widget Extension.
2. أنشئ CloudKit container باسم `iCloud.com.gaintrack.app` في Apple Developer portal.
3. اضبط فريق التوقيع (Team) الخاص بك في كلا الـ targets.

## ملاحظات معمارية

- **Local-first**: كل البيانات تُقرأ/تُكتب محليًا فورًا عبر SwiftData؛ CloudKit تتم مزامنته
  في الخلفية تلقائيًا ولا يوقف أي تفاعل مع الواجهة.
- **لا اعتماد على مكتبة الصور العامة** إلا عند طلب المستخدم الصريح للتصدير.
- **إشعار واحد فقط لكل حدث** — لا تكرار أو إزعاج.
